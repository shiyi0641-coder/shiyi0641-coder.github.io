01 / BACKGROUND

从“读懂论文”到“找到实验设计”

心理学研究生真正耗时的并不只是阅读文本， 而是从长篇论文中快速定位与自己研究问题相关的实验信息。

心理学论文通常包含大量专业术语、复杂的实验结构和丰富的方法学信息。 对研究生而言，阅读一篇论文往往不仅需要理解作者讲了什么， 还需要进一步确认被试、实验任务、干预周期、核心变量以及最终结果。

PRD 将这一问题进一步聚焦到行为实验研究。 例如认知灵活性、空间工作记忆等研究任务， 往往需要研究人员在长篇论文中反复寻找对应的实验信息。

同时，通用型阅读工具并没有针对心理学实验范式进行专门优化， 对当前研究不重要的 EEG、fMRI 等生理数据也可能增加信息筛选成本。

02 / PROBLEM

用户真正需要的是“研究信息提取”

因此产品没有把目标定义成普通的 AI 阅读器， 而是围绕心理学研究任务重新设计信息处理流程。

01

专业术语理解成本高

英文专业术语、复杂文章结构以及不同文化背景 会增加心理学研究生理解论文的成本。

02

实验信息分散

被试特征、实验任务、干预周期和因变量 往往分布在论文不同部分，需要人工反复定位。

03

非核心信息干扰

对行为实验研究而言，部分复杂生理指标并不是当前研究的重点， 但仍然增加了阅读和筛选负担。

PRODUCT GOAL
将提炼一篇文献核心实验设计的时间， 从约 30 分钟缩短到 1 分钟。

产品不是简单地生成论文摘要，而是将研究人员真正关心的信息 转化成结构化、可回溯、可继续研究的结果。

03 / AI WORKFLOW

一个围绕研究任务设计的 AI 工作流

AI 能力并不是独立存在，而是被嵌入“输入论文 → 提取研究信息 → 生成可用结果”的完整流程。

用户输入 PDF 链接 / 文本
→
PDF 解析 PDF Reader / Browser
→
大模型处理 实验拆解 / 信息过滤
→
结构化输出 Markdown / 学术大纲
→
报告交付 Word / 下载链接
核心工作流：接收链接或文本 → 解析非结构化论文内容 → 通过大模型进行行为学实验拆解与信息过滤 → 生成结构化内容 → 转换为 Word 报告。
04 / FEATURES

核心产品能力

从输入解析到研究信息提取，再到最终交付， 每一个功能都对应真实的科研阅读任务。

01

意图识别与流程分发

P0

判断用户当前是在进行日常聊天求助还是文献精读， 并自动进入对应处理流程。

02

多模态文献解析

P0

支持用户直接输入文献 PDF 网页链接， 通过 PDF Reader / Browser 获取论文正文内容。

03

行为学实验拆解

P0

结构化提取被试群体特征、样本量、基线匹配、 自变量干预周期以及核心因变量等研究信息。

04

冗余信息过滤

P1

针对行为实验研究需求过滤非核心的 EEG、fMRI 等生理数据， 保留当前研究真正需要关注的行为层面结果。

05

核心参考文献溯源

P2

从长篇 Reference 中筛选关键奠基性文献， 并给出推荐理由，帮助研究人员继续追踪研究脉络。

06

结构化视图预览

P0

将复杂研究信息整理为带有重点和层级结构的学术大纲， 直接在对话中呈现。

07

专属报告导出

P0

将结构化 Markdown 内容转换为 Word 文档， 形成可保存、可继续整理的研究资料。

05 / TRUST

AI 产品不能只追求“生成”

对科研场景而言，结果是否能够被验证和追溯， 与生成速度同样重要。

原文引用校验

对实验结果中的 p 值、效应量等关键信息， 要求模型附带原文段落引用，方便研究人员回溯原文。

异常结果提示

如果显著性指标与文字结论出现潜在矛盾， 系统进行异常提示，降低大模型幻觉带来的科研风险。

06 / V1.3

从“读一篇”走向“比较多篇”

在 V1.3 中进一步增加认知能力横向汇总， 将产品从单篇文献阅读工具扩展到研究资料整理工具。

CROSS-PAPER ANALYSIS

当用户上传多篇文献， 系统自动生成“认知能力矩阵”。

通过比较不同研究在同一认知能力或实验任务上的设置差异， 帮助研究人员快速发现不同研究之间的共同点和差异， 为后续研究设计提供资料基础。

07 / DEMO

一个实际的文献精读结果

PRD 中以一篇珠心算研究作为 Demo， 展示智能体如何将长篇论文转化为结构化研究信息。

01

文献核心速览

输出期刊、研究目的和核心假设， 让研究人员在较短时间内形成对论文的整体认识。

02

实验设计拆解

按照被试群体、自变量、因变量等结构， 提取研究设计中的关键实验信息。

03

核心结论与评价

汇总主要结果，同时对研究设计和局限进行结构化整理。

04

拓展参考文献

从参考文献中进一步筛选经典研究， 并解释推荐这些文献的原因。

08 / MY ROLE

我的工作

我负责从科研场景出发定义产品问题， 并将心理学专业需求转化为 AI Agent 的具体能力。

  • 识别心理学研究生文献阅读中的高频痛点
  • 定义产品定位、目标用户与核心产品目标
  • 将心理学行为实验信息拆解为结构化字段
  • 设计从 PDF 解析到大模型处理再到报告输出的完整工作流
  • 通过 Prompt 约束实现实验信息提取与冗余信息过滤
  • 设计原文引用与异常结果提示等准确性保障机制
  • 根据使用需求持续迭代产品，增加影响因子输出、 Word 导出以及跨文献认知能力对比等功能
09 / ITERATION

产品迭代

功能并不是一次性设计完成，而是随着实际研究需求逐步扩展。

V1.1
支持读取 PDF 网页链接、拆解文档并按照要求导出 Markdown。
2026.02.01
V1.2
增加期刊影响因子相关信息抓取与输出，并支持 Word 文档导出。
2026.02.13
V1.3
增加相同认知能力总结与跨文献实验范式对比功能。
2026
PRODUCT THINKING

把“专业知识”转化成 AI 可以执行的工作流。

这个项目最核心的产品思路，并不是让大模型泛化地“总结论文”， 而是从具体研究场景出发，定义模型应该提取什么、过滤什么、 如何组织结果，以及用户如何验证结果。 因此，心理学专业知识成为产品设计和 Prompt 设计的重要输入。
